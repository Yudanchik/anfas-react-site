# SEO-аудит anfas-react-site

Дата аудита: 15 июля 2026.

## Краткий итог

Проект уже имел базовые `title`, `description` и частично Open Graph на ключевых страницах. Главные технические пробелы были не в контенте, а в инфраструктуре индексации: отсутствовали `robots.txt`, `sitemap.xml`, canonical URL, единый подход к OG/Twitter-разметке и структурированные данные компании.

В рамках безопасных правок добавлены только технические SEO-улучшения. Дизайн, тексты секций, бизнес-логика, цены, телефоны, адреса и факты о компании не менялись.

## Исходные проблемы по приоритетам

### P0

- Критических блокеров индексации не найдено.

### P1

- Нет `robots.txt`.
- Нет `sitemap.xml`.
- Нет canonical URL на индексируемых страницах.

### P2

- Open Graph был неполным: не хватало `og:url`, `og:image`, `og:type`, `og:locale`.
- Twitter Card отсутствовал.
- Не было структурированных данных `Organization`.
- Route meta собирались вручную и могли расходиться между страницами.

### P3

- Не было route matrix для ручной проверки SEO.
- Не было чеклиста будущих SEO-доработок.
- Не было единого SEO-хелпера для новых страниц.

## Что исправлено

### Индексация

- Добавлен `public/robots.txt`.
- Добавлен `public/sitemap.xml`.
- В sitemap включены только индексируемые страницы: главная, услуги, проекты, 7 проектных страниц, о компании и контакты.
- Страница privacy не включена в sitemap, потому что остаётся `noindex`.
- 404 и privacy оставлены `noindex, nofollow`.

### Meta и canonical

- Создан единый SEO-хелпер `createSeoMeta`.
- Для всех route meta добавлены canonical URL.
- Для всех route meta добавлены `robots`.
- Для всех route meta добавлены базовые Open Graph и Twitter Card.
- Для динамических страниц проектов canonical и OG-картинка строятся по slug и изображению проекта.

### Structured data

- В `root.tsx` добавлен JSON-LD `Organization`.
- Использованы только существующие данные из `company.ts`: название, телефон, email, адрес, соцсети и официальный логотип.

### Favicon

- Добавлен favicon на существующий файл `/images/anfas-logo-official.svg`.

## Что осталось проверить вручную

- Подтвердить, что production-домен действительно `https://anfas-art.ru`.
- Проверить, что `/robots.txt` и `/sitemap.xml` доступны после деплоя.
- Проверить canonical в HTML после деплоя на production.
- Подтвердить, нужен ли отдельный PNG/WebP `og:image` размером 1200x630 для соцсетей.
- Решить, нужен ли `site.webmanifest` и набор PNG-иконок для PWA/мобильных закладок.
- При наличии юридически утверждённых данных можно расширить schema.org до более точного типа бизнеса.

## Не делалось намеренно

- Не менялись видимые тексты страниц.
- Не добавлялись отзывы, рейтинги, новые гарантии, новые цены или новые статистические факты.
- Не менялась архитектура роутинга.
- Не менялись стили и компоненты интерфейса.
- Не выполнялся push, merge, rebase, stash, reset или clean.
