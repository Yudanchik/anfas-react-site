# Локальная проверка калькулятора из ветки `dev`

Инструкция по новому простому вводу площади: [замеры пола без координат X/Y](./floor-area-guide.md).

Для калькулятора нужны два репозитория: [фронтенд](https://github.com/Yudanchik/anfas-react-site) и [бэкенд](https://github.com/Yudanchik/anfas-backend). Strapi хранит контент сайта и для проверки регистрации, личных смет и расчёта не обязателен. Нужны доступ к репозиториям, Node.js 24, pnpm 11 и запущенный Docker Desktop. Все команды ниже — для PowerShell; папку для проектов выбирайте сами.

```powershell
git clone -b dev https://github.com/Yudanchik/anfas-backend.git
git clone -b dev https://github.com/Yudanchik/anfas-react-site.git
```

В первом терминале запустите PostgreSQL и API:

```powershell
Set-Location anfas-backend
Copy-Item .env.example .env
pnpm install --frozen-lockfile
pnpm db:up
pnpm dev
```

Проверьте ответ `http://127.0.0.1:3000/api/health`. Локальные учётные данные PostgreSQL из `.env.example` предназначены только для разработки. База сохраняется в Docker volume между перезапусками; сведения о ней и API есть в [README бэкенда](https://github.com/Yudanchik/anfas-backend/blob/dev/README.md).

Во втором терминале откройте соседнюю папку фронтенда, задайте локальный режим входа и запустите сайт:

```powershell
Set-Location ../anfas-react-site
pnpm install --frozen-lockfile
@'
VITE_AUTH_MODE=nest
AUTH_BACKEND_ORIGIN=http://127.0.0.1:3000
'@ | Set-Content -Encoding utf8 .env.local
pnpm dev
```

Откройте `http://127.0.0.1:5173/auth`, зарегистрируйте локальную учётную запись с паролем не короче 10 символов и перейдите в «Мои сметы» → «Новая смета». Прямая ссылка на калькулятор — `http://127.0.0.1:5173/internal/estimate`. Не смешивайте `localhost` и `127.0.0.1` в одном сеансе. Если порт 5173 занят, освободите его перед запуском: он указан в разрешённых адресах бэкенда.

Для быстрой приёмки создайте помещение, введите размеры, пройдите сценарий стен, затем добавьте работы для пола, электрики и сантехники. Площадь пола сначала берётся из длины × ширины независимо от количества стен; для одной прямоугольной ниши или выступа укажите её ширину и глубину. Если форма сложнее, введите готовую площадь на вкладке «Полы» либо используйте точный контур. У пола проверьте покрытие и плинтус; длина плинтуса уменьшается на дверные проёмы. В электрике и сантехнике можно выбрать несколько направлений работ в одном помещении. Сохраните смету, откройте её повторно и проверьте объёмы и суммы. Отдельные технологии и состав цен ещё будут сверены с заказчиком; [вопросы для сверки](./client-scenarios-review.md).

Если нужно проверить также страницы с контентом, отдельно клонируйте [Strapi CMS](https://github.com/Yudanchik/anfas-cms) из `dev` и выполните её README. После запуска CMS на `127.0.0.1:1337` добавьте во фронтендовый `.env.local` строки `VITE_CONTENT_SOURCE=strapi` и `VITE_STRAPI_URL=http://127.0.0.1:1337`, затем перезапустите фронтенд. Одна лишь копия репозитория не переносит чужую локальную базу и загруженные в неё файлы; тестовый контент разворачивается по инструкции CMS. Для проверки калькулятора оставьте эти строки выключенными — сайт использует встроенный контент.

Файлы `.env` и `.env.local` локальные, в Git их не отправляйте. Текущий dev-сайт на REG.RU не заменяет эту локальную проверку: NestJS и CMS там пока не размещены.
