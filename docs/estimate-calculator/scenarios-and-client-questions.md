# Калькулятор сметы: действующие сценарии и вопросы заказчику

Дата: 4 октября 2026 года. Документ описывает текущую реализацию, а не утверждённую строительную технологию. Считаем только стоимость работ, без материалов.

**Просьба заказчику:** проверить деревья ниже, ответить на вопросы с номерами и прислать **2–3 законченные сметы по уже выполненным объектам** вместе с исходными замерами. По ответам уточним оплачиваемые операции, вопросы калькулятора и проверки.

## Как читать и отвечать

Последовательности показывают, какие позиции выбирает программа. Это не календарный порядок выполнения работ: например, взаимное расположение гидроизоляции и выравнивания зависит от конкретной системы и требует согласования.

Ответ на вопрос желательно записать так:

> СТ-2. Грунтование перед штукатуркой включено в её цену; отдельно оплачиваем грунт перед шпаклёвкой. Единица — м². Для исключения … применяется … .

Для каждой спорной операции нужны: условие включения, название из вашего прайса, единица, способ расчёта объёма, включённые операции и исключения. Если вариант вам не нужен — достаточно написать «не поддерживать в первой версии».

## Общая логика

```text
Новая смета → реквизиты → прайс → помещения и замеры
  → раздел работ
    → одно помещение / все участвующие помещения
    → исходное состояние и технология
    → результат и дополнительные работы
    → предварительный список и объёмы
    → применить → проверить строки → итог → экспорт
```

- Помещение общее для объекта; его размеры используются в разных разделах. При добавлении оно сначала доступно во всех разделах.
- «Убрать из раздела» исключает помещение только из текущего раздела. После подтверждения его строки здесь удаляются; другие разделы и замеры сохраняются. Через «Убранные из этого раздела помещения» комнату можно вернуть. Удалённые строки при этом не восстанавливаются сами.
- Специализированные пути кухни/санузла фильтруются по типу помещения. При массовом проходе неподходящий тип будет указан как причина пропуска; можно исправить тип или выбрать общий маршрут.
- Массовый проход использует один набор ответов, но отдельные количества каждого помещения. Исключённые помещения не участвуют. Неготовые помещения пропускаются с причиной; готовые обрабатываются.
- После успешного применения мастер возвращается на первый шаг. Отметка применения есть у помещения. Изменённые замеры требуют проверки ранее добавленных работ; они не означают автоматического пересчёта всех строк.
- «Подставить объёмы помещения» заполняет отмеченные включённые строки прайса и выбранного помещения. Общие позиции переносятся в помещение с сохранением цены/коэффициента/комментария, а исходные общие строки выключаются. Перед заменой количества есть подтверждение. Ручные строки не меняются; для плитки явно выбирается поверхность. Один кабельный метраж не подставляется массово в несколько альтернативных позиций.
- Стены поддерживают выбор «заменить / добавить». В других разделах повторный проход обновляет совпадающие позиции и отключает предусмотренные конфликтующие альтернативы; полная замена всего прежнего пакета реализована не одинаково. Поэтому при смене технологии пока нужно проверять строки на остатки предыдущего набора.
- Нулевое количество необязательной работы исключает её. Но в электрике, сантехнике и плитке наличие хотя бы одной измеренной работы ещё не подтверждает полноту всего цикла. Это ограничение текущей проверки.

## 1. Стены

### Дерево ответов

```text
Помещение / все помещения
  → что нужно сделать?
    ├─ С нуля → при необходимости снять покрытие → основание/прочность/выравнивание
    ├─ После демонтажа → основание/прочность/выравнивание; снятие не повторяется
    ├─ Уже оштукатурены → подтвердить готовность основания → подготовка под финиш
    ├─ Локально выровнять → отдельная площадь исправления
    ├─ Только демонтаж → какое покрытие снимаем?
    └─ Только финиш → подготовка уже выполнена
  → сухая зона или прямое попадание воды?
  → без финиша / обои / окраска
  → Q2 / Q3 / Q4, вид обоев или окраски, стеклохолст по необходимости
  → откосы: не делать / выбранный пакет по измеренной длине
  → список → применить; при повторе заменить или добавить
```

### Что собирается

| Условие                                     | Работы текущего сценария                                                                                            |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Демонтаж                                    | Одна выбранная позиция: снятие обоев, краски, штукатурки, плитки либо стеклохолста; объём — площадь демонтажа       |
| Полное выравнивание сухой минеральной стены | Обеспыливание, грунт под штукатурку, маяки, гипсовая штукатурка, после высыхания грунт перед шпаклёвкой, дальнейшая подготовка |
| Локальное выравнивание в полном маршруте    | Подготовка основания, локальная операция по указанной площади, затем подготовка и выбранный финиш                   |
| Уже оштукатурено                            | Обеспыливание, грунтование, шпаклёвка и шлифовка; сплошная штукатурка не повторяется                                |
| Отдельный маршрут локального исправления    | Обеспыливание, локальная шпаклёвка до 3 мм, шлифовка; это не весь цикл отделки стены                                |
| Q2                                          | Базовая шпаклёвка 1 слой, шлифовка                                                                                  |
| Q3                                          | Базовая шпаклёвка 2 слоя, финишная 1 слой, шлифовка                                                                 |
| Q4                                          | Базовая шпаклёвка 2 слоя, финишная 2 слоя, шлифовка                                                                 |
| Подготовка под окраску со стеклохолстом     | Дополнительно монтаж стеклохолста и соответствующая финишная подготовка                                             |
| Обои                                        | Грунтование под отделку и выбранная позиция поклейки; тип и подбор рисунка меняют позицию                           |
| Окраска                                     | Выбранная позиция окраски; гладкая окраска требует Q3/Q4 в текущем мастере                                          |
| Прямое попадание воды                       | Черновое цементное выравнивание подходящей минеральной стены; обои/краска и гидроизоляция в этот путь не включаются |
| Только финиш                                | Выбранное покрытие без повторной штукатурки и шпаклёвки                                                             |
| Откосы                                      | Отдельный пакет по выбранному ответу и длине отмеченных проёмов; при отсутствии откосов работы не добавляются       |

Грунт перед выбранной окраской или оклейкой считается отдельно от грунта перед шпаклёвкой. Между базовой и финишной шпаклёвкой проход добавляется только по отдельному ответу для конкретной системы; тарифные пересечения нужно подтвердить. Q2–Q4 в программе — ориентир требуемого результата. Нельзя гарантировать категорию поверхности только количеством слоёв. Для типовой облицовки ГКЛ мастер различает существующую конструкцию и новый каркас с одним/двумя слоями; лента и заделка швов рассчитываются по отдельному замеру длины, крепёж и подготовка — по площади. Углы/примыкания и сложные конструкции остаются для ручной проверки. Позиции взяты из PDF-прайса (стр. 1–2 и 8). Часть тарифов уже включает операции, поэтому их нельзя складывать без проверки состава. Неизвестное или непрочное основание даёт объяснение и частичный предпросмотр, но не подтверждённую полную технологию.

Площадь стен: сумма ширина × высота минус отмеченные проёмы. Можно вместо подробных замеров ввести готовую площадь. Откосы считаются отдельно: две вертикальные стороны + верх; четвёртая сторона добавляется по выбору. Площадь откосов по глубине автоматически не подменяет погонные метры.

### Вопросы

1. **СТ-1. Основания.** Для кирпича, блока, бетона, готовой штукатурки и ГКЛ какие системы реально используете? Какие проверки прочности, влажности, трещин и перепадов меняют работы? Нужны ли демонтаж слабой штукатурки и ремонт трещин отдельными вопросами?
2. **СТ-2. Пакеты и грунтование.** Какие из проходов оплачиваются отдельно: под штукатурку, по высохшей штукатурке/ГКЛ перед шпаклёвкой, перед окраской или обоями? В каких ваших системах нужен грунт между базовой и финишной шпаклёвкой? Что включено в тарифы штукатурки/шпаклёвки: обеспыливание, грунт, маяки и их удаление, сетка, шлифование?
3. **СТ-3. Выравнивание.** Какие допустимые толщины, границы локального и сплошного исправления, разные цены по слоям? Достаточно ли площади или нужна толщина/перепад?
4. **СТ-4. Финиш.** Подтвердите фактические пакеты под фактурные/тонкие обои, матовую/глянцевую краску. Где необходим стеклохолст? Что считать отдельно: грунт между этапами, слои краски, подбор рисунка, сложные обои?
5. **СТ-5. Проёмы и откосы.** Все ли окна/двери вычитать из площади каждой операции? Есть ли порог площади проёма? Как оплачивать откосы по ширине/глубине, нижнюю сторону окна, уголки и примыкания? Выберите единицы и состав пакета.
6. **СТ-6. Влажная зона и ГКЛ.** Какие пути нужны в первой версии? Подтвердите, какие операции швов/углов ГКЛ уже входят в монтаж листов и какие считаются отдельно; как обрабатываете влажные стены. Где заканчиваются стены и начинается плитка/гидроизоляция?

## 2. Полы

### Дерево и работы

```text
Помещение / все помещения
  → старое покрытие: нет / ламинат / линолеум / плитка / паркетная доска / стяжка
    → соответствующий демонтаж по отдельной площади
  → выравнивание:
    ├─ не нужно → нет работ по выравниванию
    ├─ ровнитель → обеспыливание + грунтование + устройство ровнителя
    ├─ мокрая стяжка: до 50 / 50–80 / свыше 80 мм
    │   → подготовка + обеспыливание + грунтование + выбранная стяжка
    └─ полусухая: до 80 / свыше 80 мм
        → подготовка + обеспыливание + грунтование + выбранная стяжка
  → гидроизоляция: нет / акриловая 1 слой / 2 слоя
    → выбранная операция только по мокрой площади
```

Для демонтажа стяжки текущий пакет использует позицию до 70 мм. Объём выравнивания — отдельная площадь стяжки либо площадь пола, если отдельная не заполнена. Мокрая площадь 0 не блокирует другие работы сухой комнаты; гидроизоляция пропускается. Если выбрана только гидроизоляция и площадь 0 — добавлять нечего, требуется уточнение.

Подготовка финишного покрытия, ламинат/кварцвинил/паркет, плинтус, демпферная лента, плёнка, сетка, швы и вывоз мусора не возникают автоматически из этих ответов. Дополнительные позиции доступны через прайс. Старые самостоятельные пакеты демонтажа/стяжки/ровнителя/мокрых зон/мусора сохраняются в модели для совместимости сохранённых смет.

### Вопросы

1. **ПЛ-1. Покрытия.** Какие виды старого пола и толщины демонтажа нужны, включая несколько слоёв и стяжку толще 70 мм? Как их измерять и оплачивать?
2. **ПЛ-2. Основание.** По каким измерениям выбирать ровнитель, мокрую и полусухую стяжку? Нужны ли вопросы о прочности, влажности, перепаде, связанной/плавающей системе? Для каждой системы укажите обязательные работы и диапазоны толщины.
3. **ПЛ-3. Состав цены.** Плёнка, лента, сетка, маяки, швы, уход, шлифование, ремонт основания, шумоизоляция — что входит в цену стяжки, что отдельная строка? Шлифование нужно не выводить из любого ответа «мокрая стяжка», а привязать к вашей системе.
4. **ПЛ-4. Гидроизоляция.** Где и в какой последовательности её делать? Какие площади, слои, примыкания и проходки считать? В каком одном разделе показывать, если сверху плитка?
5. **ПЛ-5. Финиш и мусор.** Какие покрытия добавить в мастер; какие работы входят в их укладку? Какие отдельные замеры нужны для плинтусов и выноса/вывоза мусора?

## 3. Потолки

### Дерево и работы

```text
Помещение / все помещения
  → с нуля / после демонтажа / уже оштукатурено / локально / только демонтаж / только финиш
  → для полного пути: основание и подтверждение прочности
  → при необходимости снять старое покрытие
  → без финиша / окраска
  → Q2 / Q3 / Q4, стеклохолст, выбранная окраска
  → список → применить
```

| Маршрут                                      | Текущие работы                                                                                         |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| С нуля, подготовленное минеральное основание | Обеспыливание, грунт под штукатурку, маяки, штукатурка потолка, удаление маяков, шпаклёвка, шлифовка   |
| После демонтажа                              | Подготовка как выше; при новых ответах демонтаж повторно не добавляется                                |
| Уже оштукатурено                             | Обеспыливание, грунтование, шпаклёвка и шлифовка                                                       |
| Локально                                     | Обеспыливание, локальная шпаклёвка до 3 мм, шлифовка                                                   |
| Только демонтаж                              | Выбранное снятие покрытия по площади демонтажа                                                         |
| Только финиш                                 | Выбранная окраска без полного цикла подготовки                                                         |
| Q2 / Q3 / Q4                                 | Один базовый слой / два базовых + один финишный / два базовых + два финишных; соответствующая шлифовка |
| Стеклохолст                                  | Дополнительная работа только по ответу о необходимости при подготовке под окраску                      |

Площадь потолка подставляется из площади комнаты, пока пользователь не изменил её отдельно. Объёмы штукатурки, шпаклёвки и финиша можно уточнять. Монтаж натяжных/подвесных потолков не является автоматически выбранным полным путём. Типовой одноуровневый потолок ГКЛ доступен как один или два слоя; его тариф уже включает каркас и листы, швы измеряются отдельно. Сложные потолочные системы и углы остаются для ручной проверки; неизвестное/непрочное основание требует уточнения.

### Вопросы

1. **ПО-1. Системы.** Какие потолки нужны: бетон, готовая штукатурка, ГКЛ, натяжной, подвесной? Нужен ли монтаж конструкций или только подготовка/окраска/демонтаж?
2. **ПО-2. Пакеты.** Подтвердите оплачиваемый состав полного, локального и финишного пути, ограничения толщины, маяки и их снятие, грунты, армирование. Какие операции входят в основные цены?
3. **ПО-3. Качество.** Какие реальные пакеты под разные покрытия и критерии результата? Где стеклохолст обязателен, сколько слоёв шпаклёвки/краски оплачивается отдельно?
4. **ПО-4. Геометрия.** Как измерять короба, ниши, карнизы и перепады уровня: м², погонные метры или штуки? Нужны ли отдельные площади и периметры?

## 4. Плитка

### Дерево

```text
Помещение / все помещения
  → санузел с нуля / замена / пол / стены / фартук / крупный формат / демонтаж / ремонт
  → формат: 301–1300 / 1301–1700 / 1701–3600 / >3600 / мозаика / мелкоштучка
  → затирка: нет / цементная / эпоксидная, где предусмотрено маршрутом
  → для демонтажа: пол / стены / оба
  → измеренные операции → применить
```

Исходный PDF-прайс, стр. 17, прямо указывает диагональ плитки в миллиметрах для диапазонов 301–1300, 1301–1700 и далее; цена облицовки указана за м². Не подменять диагональ длиной стороны плитки.

| Маршрут                 | Набор позиций                                                                                                                  |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Санузел с нуля          | Обеспыливание, грунтование, раскладка, выбранная облицовка, выбранная затирка и её очистка                                     |
| Замена в санузле        | Демонтаж плитки пола и стен по соответствующим площадям, затем пакет санузла с нуля                                            |
| Пол / стены             | Раскладка, выбранная облицовка по соответствующей площади, выбранная затирка и очистка                                         |
| Фартук                  | Раскладка и выбранная облицовка по площади фартука; выбранная затирка и её очистка                                             |
| Крупный формат          | Раскладка, выбранная облицовка, подготовка кромки и отверстия при наличии соответствующих замеров; выбранная затирка и очистка |
| Только демонтаж         | Выбранные поверхности; новые работы не включаются                                                                              |
| Только затирка / ремонт | Цементная/эпоксидная затирка и очистка; при ответе «без затирки» — замена отдельной плитки по количеству ремонта               |

Здесь важны **отдельные** площади облицовки пола, стен и фартука; общая площадь стен не означает всю стену в плитке. Подрезка, углы, отверстия и ремонт имеют собственные замеры. Само наличие позиции в прайсе не означает её включения в каждый пакет.

### Вопросы

1. **ПТ-1. Формат.** Диагональ плитки в мм и цена облицовки за м² подтверждены исходным прайсом. Самостоятельно проверить, что этот смысл виден в вопросе мастера; заказчику оставить только выбор часто применяемых видов плитки, если он потребуется.

## 5. Электрика

### Дерево

```text
Помещение / все помещения
  → с нуля / перекоммутация / кухня / санузел / освещение / розетки / слаботочка / щит / демонтаж
  → перед новым монтажом снять старые приборы? да / нет
  → стена: бетон / кирпич / ГКЛ / готовые отверстия / неизвестно
  → кабель: открыто / в штробе / смешанный / уже проложен / неизвестно
  → отдельные старые и новые точки, метры кабелей и новой штробы
  → измеренные позиции → применить
```

### Базовые наборы

| Маршрут                | Какие операции может добавить программа при наличии замеров                                                                                                              |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Квартира с нуля        | Разметка трасс и точек, штробление, прокладка кабеля, отверстия, фиксация подрозетников, соединения Wago, корпус и сборка щита, механизмы, точечный свет, проверка групп |
| Перекоммутация комнаты | Разметка точек, штробление, кабель, отверстия, подрозетники, механизмы и точечный свет                                                                                   |
| Кухня                  | Штробление, кабель, отверстия, подрозетники, механизмы, подключение техники                                                                                              |
| Санузел                | Штробление, кабель, отверстия, подрозетники, влагозащищённые розетки, точечный свет, заземление ванны, подключение готового электрического полотенцесушителя             |
| Только освещение       | Монтаж точечных светильников; полный цикл новой проводки этим ответом не создаётся                                                                                       |
| Розетки и выключатели  | Финишный монтаж механизмов; новая трасса автоматически не включается                                                                                                     |
| Слаботочка             | Кабель UTP, розетки RJ45, проверка интернета                                                                                                                             |
| Щит                    | Корпус 12/18/24 модуля, сборка соответствующего щита, проверка; число корпусов — 1 при допустимом положительном числе модулей                                            |
| Демонтаж               | Снятие старых розеток/выключателей, светильников, кабеля по отдельным старым замерам                                                                                     |

Материал стены заменяет бетонные позиции на кирпичные или отверстия в ГКЛ. Для готовых отверстий новые отверстия не добавляются. Штробление ГКЛ недоступно. Неизвестный материал/маршрут требует ответа, если от него зависит работа. Позиции с ручным количеством, включая некоторые проверки, могут отсутствовать в автоматическом наборе — их надо отдельно согласовать.

### Количества

- Подрозетники предварительно равны розеткам + выключателям + слаботочным точкам. Ручное отклонение сохраняется при последующих правках точек.
- Демонтаж использует старые счётчики; новый монтаж — новые. В старом самостоятельном сценарии демонтажа без отдельных старых замеров сохраняется прежнее поведение до редактирования.
- Раздельные поля кабеля: открыто на крепёж и в штробе; их сумма заполняет общий кабельный метраж. Выбираем смешанный маршрут для двух позиций. Переход к общему метражу возможен кнопкой; общий метраж в раздельном режиме отображается как сумма, без отдельного редактирования.
- Пример: 80 м открыто + 20 м в штробе → две позиции прокладки. Два кабеля по 10 м в одной новой штробе → 20 м кабеля, 10 м штробления. Готовая штроба → 0 м нового штробления. Проценты не определяют длину штробы.
- Сейчас быстрый смешанный путь использует кабель 1,5–2,5 и штробу до 35 из прайса. Другие сечения доступны через прайс с подстановкой соответствующего открытого/штробного метража. Разные сечения одновременно, гофра/труба/лоток, ширины и смешанные материалы стены требуют отдельных замеров и согласования.
- Модули щита, коробки и проверки не выводятся надёжно из числа розеток: нужна схема.

### Вопросы

1. **ЭЛ-1. Трассы.** Какие способы и сечения поддерживать: крепёж, готовая/новая штроба, гофра, труба, лоток, каркас? Что включено в цену прокладки, где нужны отдельные штробление и заделка? Как считаются общие участки и кабельные запасы?
2. **ЭЛ-2. Точки.** Подтвердите механизм/подрозетник/монтажную точку как единицы. Как считать блоки, накладные и готовые места, многоклавишные выключатели, светильники разных типов и распаечные коробки?
3. **ЭЛ-3. Пакеты.** Нужен ли полный цикл новой проводки для «только освещение» и «розетки», в отличие от финишной установки? Какие обязательные операции сейчас отсутствуют, какие входят в основную цену?
4. **ЭЛ-4. Щит и проверки.** Как считать корпуса, модули, аппараты, соединения, маркировку, заземление и испытания? Дайте набор оплачиваемых операций по реальной схеме, включая большие щиты и разные корпуса.
5. **ЭЛ-5. Санузел и демонтаж.** Когда нужны заземление ванны и подключение полотенцесушителя? Как измерять демонтаж и какие операции уже включены в замену точки?

## 6. Сантехника

### Дерево

```text
Помещение / все помещения
  → санузел с нуля / замена / кухня / ванная / туалет / коллектор / канализация / вода / приборы / демонтаж
  → приборы и отдельные старые приборы при замене
  → унитаз: напольный / подвесной; новая / существующая рама
  → ванна: акрил / чугун / кварил
  → душ: поддон / кабина
  → раковина: обычная / настенная / накладная / врезная
  → выводы, трубы и дополнительные количества
  → измеренные позиции → применить
```

### Базовые наборы

| Маршрут              | Набор, из которого выбираются работы с измеренным количеством                                                                                                          |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Санузел с нуля       | Разводка и трубы канализации, фиксация выводов; разводка и трубы воды, водорозетки, опрессовка; рама/подключения при новой инсталляции; выбранные приборы, запуск воды |
| Замена               | Демонтаж старого унитаза/раковины/ванны/смесителя по отдельным количествам; выбранные новые приборы; проверка финишного монтажа                                        |
| Кухня                | Трубы и выводы воды/канализации, кухонная мойка и смеситель, посудомоечная машина, опрессовка                                                                          |
| Ванная               | Выбранная ванна или душ, сифон ванны; смесители требуют уточнения по месту и типу                                                                                      |
| Туалет               | Выбранный унитаз; для новой рамы — её монтаж и подключения; канализационная труба 110, водопроводная труба и выводы                                                    |
| Коллектор            | Накладной шкаф, гребёнка, ввод, фильтр, редуктор, счётчик, опрессовка; без схемы и отдельных ручных количеств пакет может быть неполным                                |
| Только канализация   | Разводка, труба 32–50, фиксация вывода, уклон и промывка по имеющимся измерениям                                                                                       |
| Только водоснабжение | Разводка, труба 16–20, выводы и их фиксация, опрессовка                                                                                                                |
| Приборы              | Выбранный унитаз/раковина/ванна/душ по актуальным ответам, подключения машин, проверка; тип смесителя не угадывается из общего счётчика                                |
| Только демонтаж      | Старые унитазы, раковины, ванны, смесители; новый монтаж не входит                                                                                                     |

Названные проверки/соединения с ручным количеством не добавляются только по названию маршрута. Это кандидаты для согласования, а не гарантированные строки итогового пакета.

### Автозаполнение

- Для нового помещения типовая предварительная схема: раковина/ванна/душ — 2 вывода воды и 1 канализации; унитаз и машины — по 1 воды и канализации.
- Предварительное число смесителей = раковины + ванны + души. Это допущение для обычных отдельных приборов; общий или скрытый смеситель требует исправления.
- Инсталляций столько же, сколько унитазов, **только** при явно выбранной новой раме. Напольный унитаз или уже готовая рама не создают новую инсталляцию.
- Ручной режим выводов и ручной режим смесителей/инсталляций независимы. Старые сметы не переводятся в автоматический режим без действия пользователя.
- При замене старые приборы измеряются отдельно. Например, снять 1 старую раковину и установить 2 новые — разные количества. Для самостоятельного демонтажа старой сметы без новых полей сохраняется прежнее поведение; перед применением нужно проверить старые количества.
- Общий счётчик смесителей пока не распределяется автоматически между раковиной, ванной, душем и кухней. Часть таких позиций добавляется вручную после уточнения типа.
- Длины труб, коллекторы, оборудование и испытания требуют схемы; обратный вывод числа приборов из водорозеток неоднозначен.

### Вопросы

2. **САН-2. Типы приборов.** Для каждого типа унитаза, раковины, ванны, душа дайте необходимые работы и единицы. Какие дополнительные вопросы нужны: новые/готовые подключения, крепления, сифон, строительный душ, трап?

## 7. Общие вопросы и проверка реальными объектами

1. **ОБ-1. Прайс.** Для каждой строки указать включённые операции, единицу, минимальную стоимость, округление, коэффициенты сложности. Есть ли разные ставки для чернового и локального ремонта? Можно прислать текущий рабочий прайс с пояснениями.
2. **ОБ-2. Границы.** Где учитывать один раз демонтаж плитки, гидроизоляцию, подготовку под плитку, штробы и их заделку, мусор? Общие проверки/щит/коллектор — на комнату или на объект? Какие пары позиций нельзя выставлять одновременно?
3. **ОБ-3. Неизвестные данные.** При незаполненном обязательном замере блокировать весь пакет или разрешать явно помеченный частичный черновик? Нужно различать «работа не нужна» и «ещё не измерено»; согласуйте это для каждого обязательного этапа.
4. **ОБ-4. Повторное применение.** Подтвердите желаемое правило: заменить автоматически добавленный набор или дополнить его, сохраняя ручные работы. Нужно ли сохранять несколько разных технологий/участков в одном помещении?
5. **ОБ-5. Первая версия.** Отметьте обязательные технологии и редкие варианты, которые допустимо оставить ручными. Готовность оцениваем по этому согласованному набору, а не по всем возможным строительным случаям.

### Просим 2–3 сметы по выполненным объектам

Желательно разные случаи:

1. Полный ремонт: стены/полы/потолки, черновая подготовка и финиш.
2. Санузел или кухня: плитка, гидроизоляция, сантехника и электрика.
3. Частичная замена/локальный ремонт: старые и новые приборы, смешанная кабельная трасса либо уже подготовленное основание.

Для каждой: фактические помещения и замеры, исходное состояние, выбранная технология/финиш, перечень выполненных работ, единицы, количества, цены, итог и включённые в тариф операции. Можно обезличить адреса и заказчиков. Если итоговая смета отличается от первоначальной, желательно пояснить изменения.

Сверим построчно: обязательные операции, отсутствие дублей, единицы, объёмы, цены и итог с согласованным округлением. Наличие пары совпавших итогов не доказывает правильность всех веток: важно объяснить совпадение состава и количеств. Новые технологии будем добавлять по мере необходимости.

## 8. Что дорабатывается на стороне разработки

- Единое происхождение автоматических строк и одинаковый режим «заменить / добавить» во всех разделах. Защитить дополнительные строки прайса при смене пакета.
- Проверка полноты обязательных этапов: не представлять одну измеренную работу как весь готовый цикл.
- После ответов — уточнение тарифных пакетов, разделение общих работ на объект, расширение сложных ГКЛ/финишных/инженерных систем.
- Разделение смесителей по типу/месту; дополнительные кабельные сечения и участки трасс, если требуются первой версии.
- Регрессионные проверки по предоставленным сметам и сохранение всех новых ответов вместе со сметой.

Эти задачи не требуют от заказчика проектировать интерфейс. Нужны его рабочие правила, тарифы и реальные примеры.
