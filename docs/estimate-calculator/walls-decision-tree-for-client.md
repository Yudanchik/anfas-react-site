# Сценарий стен: дерево вопросов и работ для согласования

Версия 2026-10-03. Считаем **только работы**, по каждому помещению отдельно. Материалы, расход, гидроизоляцию и плитку этот сценарий не добавляет. Количества берутся из замеров помещения: площадь стен, уточнённая площадь штукатурки/шпаклёвки/финиша, длина откосов. Перед выдачей заказчику смету проверяет специалист на объекте.

## Как читать дерево

1. Выбрать одно помещение или несколько с **одинаковым** состоянием и технологией. Для разных оснований пройти мастер отдельно.
2. Ответить на вопросы о том, что уже сделано, что предстоит снять, из чего стена, прочна ли она, какой объём выравнивания нужен и есть ли прямое попадание воды.
3. Выбрать результат: без финиша, обои или краска; уточнить категорию подготовки Q2/Q3/Q4, конкретное покрытие, при необходимости стеклохолст и откосы.
4. Посмотреть работы и объёмы, затем добавить их. Если сценарий уже применён, выбрать **заменить** или **добавить**. Ручные строки при замене сохраняются.

Предпросмотр строится с первого шага. Когда ответы указывают на непроверенное или несовместимое основание, уже определившиеся работы остаются видны, но применение неполного маршрута блокируется с конкретной причиной. Это намеренное правило: нельзя получать пустой экран, но нельзя выдавать неполную технологию за готовую смету.

## Дерево: исходное состояние

| Ответ | Что собирается до выбора отделки | Дополнительные вопросы |
| --- | --- | --- |
| **С нуля** | Обеспыливание → грунт под штукатурку → выравнивание → подготовка поверхности | Нужно ли сначала снять покрытие? Основание, прочность, площадь выравнивания, влага |
| **Демонтаж уже выполнен** | Как «С нуля», но без повторного демонтажа | Основание, прочность, выравнивание, влага |
| **Стены уже оштукатурены** | Обеспыливание → грунт → шпаклёвка/шлифовка по качеству | Подтвердить прочность готовой штукатурки, влага |
| **Только локально выровнять** | Обеспыливание → локальная шпаклёвка до 3 мм → шлифовка | Нужна отдельная площадь локальной шпаклёвки; отделка всей стены не входит |
| **Только снять старое покрытие** | Один вид демонтажа по выбранному покрытию | Вид снимаемого покрытия; новая подготовка не входит |
| **Основание готово — только финиш** | Выбранные обои или окраска, без повторной подготовки | Пользователь подтверждает, что подготовка уже завершена; выбрать покрытие |

Если при маршруте «С нуля» выбрать снятие покрытия, перед подготовкой добавляется **одна** позиция демонтажа: обои, краска, штукатурка, стеновая плитка либо стеклохолст. Состояние «после демонтажа» не добавляет снятие второй раз. Снятие рыхлых участков не выводится автоматически из общего ответа «основание непрочное»: его вид и площадь требуют осмотра.

## Дерево: основание, объём и влажность

| Ответ | Изменение списка/правило |
| --- | --- |
| **Минеральное основание** (кирпич, блок, бетон) | Типовой путь штукатурки. Для впитывающих и плотных оснований материалы грунта подбираются по-разному, но стоимость материалов здесь не считается; трудовая позиция грунтования одна. |
| **Готовая штукатурка** | Сплошную штукатурку не повторяем в маршруте «уже оштукатурены». Для другого маршрута работа зависит от требуемого выравнивания. |
| **Гипсокартон** | Не добавляем гипсовую/цементную штукатурку как будто это кирпичная стена. Если швы и поверхность уже готовы, выбирать «только финиш». Полный путь ГКЛ заблокирован до согласования отдельной цены и замера швов. |
| **Материал неизвестен / прочность не проверена / есть рыхлость или сырость** | Видны подтверждённые работы, например снятие покрытия и обеспыливание. Автоматическая последующая отделка не применяется до осмотра. |
| **Выровнять всю стену** | Грунт → маяки → сплошная штукатурка. В сухой зоне гипсовая, в зоне прямой воды — цементная черновая штукатурка. |
| **Локальное выравнивание** | Грунт → локальное исправление/штукатурка по отдельно указанной площади; затем подготовка и выбранный финиш всей площади, если они нужны. |
| **Плоскость ровная** | Сплошной штукатурки нет. Для необработанного минерального основания это надо подтвердить осмотром и совместимостью шпаклёвки. |
| **Прямое попадание воды** | Предлагается только черновое цементное выравнивание по полной площади на подходящем минеральном основании. Покрытие, гидроизоляция и совместимость конкретной системы требуют отдельного выбора; вместе с обоями/краской этот маршрут не применяется. |

Грунт перед гипсовой штукатуркой и его **материал** надо выбрать по фактическому основанию: на впитывающих поверхностях регулируют водопоглощение, на гладком бетоне используют адгезионный грунт. Грунтование не заменяет удаление пыли. Это следует из [инструкции КНАУФ по Ротбанду](https://www.knauf.ru/upload/iblock/6e9/3sc14u5cbrzyh0d0dd9jm23mvokvp145/01_IL_KNAUF_Rotband_25_03_2025_v01_Preview.pdf); названия материалов здесь **не** превращаются в цены материалов.

## Дерево: качество, отделка и откосы

| Ответ | Добавляемые работы |
| --- | --- |
| **Q2** | Базовая шпаклёвка 1 слой → шлифовка. Ориентир для рельефных/фактурных обоев. Для гладкой окраски Q2 недостаточно. |
| **Q3** | Базовая шпаклёвка 2 слоя → финишная шпаклёвка 1 слой → шлифовка. Ориентир для тонких обоев и матовой окраски. |
| **Q4** | Базовая шпаклёвка 2 слоя → финишная шпаклёвка 2 слоя → шлифовка. Ориентир для требовательного глянцевого покрытия; реальное качество надо принимать на объекте. |
| **Стеклохолст по проекту** | Монтаж стеклохолста + финишная шпаклёвка, если выбран путь подготовки под краску. Не добавляется просто потому, что выбрана краска. |
| **Обои** | После подготовки грунтование в 1 слой → один вид поклейки: флизелин, винил с подбором, фотообои либо тканевые с подбором. Тонкие фото-/тканевые обои при Q2 требуют уточнить более гладкую подготовку. |
| **Краска** | После подготовки грунтование в 1 слой → одна позиция окраски: валиком 1/2/3 слоя либо механизированно 2 слоя. Q2 в этом маршруте не принимается как гладкая окраска. |
| **Без финиша** | Обои/краска не добавляются; черновая подготовка остаётся, если она выбрана. |
| **Откосы: шпаклёвка/окраска** | Шпаклевание откосов 2 слоя → шлифовка → окраска валиком 2 слоя. |
| **Откосы: сэндвич** | Монтаж сэндвич-панелей вместо шпаклёвки и окраски. |
| **Откосов нет** | Ничего не добавляется; в режиме нескольких помещений откосы появляются только там, где измерена их длина. |

Q1–Q4 у [КНАУФ](https://www.knauf.ru/company/technology/sistema-q1-q4/) — категории **требуемого результата и проверки поверхности**, а не гарантированное число слоёв. Таблица выше показывает текущие *ценовые пакеты работ* проекта; состав и расход конкретной системы нужно согласовать с технадзором. Для ГКЛ [КНАУФ отдельно требует обработку швов с армирующей лентой](https://www.knauf.ru/company/technology/sistema-q1-q4/q2/); в нашем прайсе пока есть лишь расшивка незаводских швов, поэтому мастер не подменяет полный путь одной строкой.

## Правила количества и повторного применения

- Демонтаж: отдельная площадь демонтажа, иначе площадь стен. Сплошная штукатурка: отдельная площадь штукатурки, иначе площадь стен. Шпаклёвка и финиш: отдельные площади, иначе площадь стен. Откосы: только измеренные погонные метры.
- При локальной штукатурке/шпаклёвке отдельную площадь надо заполнить; если её нет или она больше площади стен, сценарий не применится.
- Работы каждого помещения создаются отдельными строками. Повторное применение того же сценария не дублирует его строки. «Заменить» убирает прежние строки сценария комнаты, сохраняя ручные и добавленные из прайса; «Добавить» дополняет имеющиеся.
- Сценарий заполняет **черновик**. После замеров и добавления проверить фактические объёмы, необходимость слоёв и совместимость работ, затем сохранить смету.

Пример заказчика в Excel («Ввод.данных» → «Смета») подтверждает удобный принцип: помещения и площади работ задаются отдельно, а результат собирается по этим величинам. Из файла **не следует** универсальное дерево технологии; приведённые здесь условия сформулированы отдельно и требуют вашего согласования.

## Вопросы заказчику: нужны конкретные правила, а не только названия операций

Пожалуйста, отвечайте для **типового ремонта, который вы реально считаете**. Если правило зависит от осмотра, укажите измеряемый признак или оставьте работу на ручное решение. Для каждого автоматического шага важно понять: когда он обязателен, когда не нужен, какая единица и площадь/длина его определяют.

### 1. Состояние и демонтаж

1. Какие исходные состояния достаточно различать: голый кирпич/блок/бетон; прочная старая штукатурка; стены после демонтажа; ГКЛ с готовыми или незаделанными швами; готовая под финиш поверхность? Что именно считается «готово под финиш»: шпаклёвка, шлифовка и грунт уже сделаны или грунт добавлять отдельно?
2. Если есть старые обои, краска, плитка, стеклохолст, слабая штукатурка: снимаем покрытие **полностью или местами**? Может ли быть несколько слоёв, которые нужно считать отдельными работами? Откуда берётся площадь каждого слоя?
3. Что делать при отслоениях, трещинах, следах сырости или плесени: какие работы допустимо автоматически предлагать, а какие всегда требуют осмотра и устранения причины? Нужно ли отдельное поле площади ремонта?

### 2. Подготовка и выравнивание

4. Для каких оснований и условий выбирать гипсовую, цементную или иную систему? Считать ли гладкий бетон и впитывающий блок разными **работами** по грунтованию при нашем прайсе без материалов, или различие остаётся только в техкарте?
5. По какому измеримому правилу выбирать «без выравнивания», «локально» или «всю стену»? Для локальной работы нужна площадь каждого участка или достаточно общей площади по комнате? Есть ли порог толщины/неровности, после которого меняется позиция работы?
6. Маяки обязательны для всей сплошной штукатурки или зависят от требуемой геометрии? Снимать ли маяки после штукатурки; добавлять ли контактный слой, сетку и дополнительный слой свыше 40 мм; при каких условиях и с какими объёмами?
7. На каких этапах отдельно оплачиваются обеспыливание, грунтование и шлифовка: до штукатурки, после неё, между шпаклёвочными слоями и перед обоями/краской? Одну и ту же позицию прайса можно считать дважды или это входит в пакет следующей работы?

### 3. Желаемый результат

8. Какие финиши реально нужны в типовом объекте: флизелин, винил с подбором, фото-/тканевые обои, матовая/глянцевая краска, плитка, декоративная отделка? Какие из них следует считать именно в сценарии стен, а какие — в отдельном разделе, чтобы не было дублей?
9. Какое качество подготовки требуется для **каждого** финиша на ваших объектах? Подтвердите конкретные платные операции и число слоёв для Q2, Q3 и Q4. Нужны ли отдельная финишная шлифовка и проверка косым светом? Само число слоёв не гарантирует категорию качества.
10. Когда стеклохолст или штукатурная сетка обязательны, когда только по проекту и когда не нужны? Нужны ли отдельные работы по их приклейке, последующему шпаклеванию и грунту?

### 4. Особые основания, мокрые зоны, откосы

11. Для ГКЛ перечислите полный оплачиваемый путь: расшивка обрезных кромок, заделка швов с лентой, крепёж, углы/примыкания, грунт, сплошная шпаклёвка, шлифовка, финиш. Какие позиции и цены отсутствуют в текущем прайсе? Как замерять длину швов и углов?
12. Что именно означает «мокрая зона» на ваших объектах: вся ванная или только стены с прямым попаданием воды? Какая система основания и покрытия применяется в каждом случае; кто в смете добавляет гидроизоляцию, плитку и герметизацию примыканий?
13. Какие откосы считать по умолчанию: штукатурные, шпаклёванные и окрашенные, сэндвич или иной вариант? Какие стороны проёма включать; нужен ли отдельный учёт глубины, углов и демонтажа старых откосов?

### 5. Правила сметы и проверка на реальных объектах

14. Для каждой работы подтвердите единицу цены и источник количества: площадь всей стены без проёмов, отдельная площадь участка, погонные метры либо ручной замер. Какие работы уже включены в цену другой позиции и не должны появляться второй раз?
15. При недостаточном замере или неизвестной технологии что предпочтительнее: блокировать применение сценария с причиной, показывать предварительную строку с пометкой «уточнить», либо разрешать ручное подтверждение ответственного сметчика? Укажите, **кто** имеет право принять такое решение.
16. Передайте **5–10 обезличенных завершённых смет по разным типовым случаям** вместе с исходными замерами и объяснением, почему каждая работа включена. Нужны как минимум: стены с нуля; демонтаж и новый цикл; прочная старая штукатурка; локальный ремонт; ГКЛ; мокрая зона; разные финиши. Мы прогоним те же вводные в калькуляторе и сверим состав **и объёмы построчно**. Отдельно зафиксируем допустимые расхождения и исключения.

Ответы на 1–15 дадут правила для настройки, а пункт 16 покажет, насколько они действительно покрывают практику. Только после сравнения с реальными сметами можно оценивать полноту; «99,9%» нельзя обещать по одному списку вопросов или по техническим картам производителя. После согласования дерево и правила меняются в `src/entities/estimate/model/walls/apply-wall-scenario.ts`; тексты вопросов — в `src/features/estimate-calculator/walls/wall-scenario-questions.ts`.
