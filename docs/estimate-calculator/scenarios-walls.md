# Раздел «Стены»

Краткая инструкция для сметчика. Сценарий — быстрый черновик: после применения строки можно править вручную.
**Материалы не считаются** — только работы (в т.ч. labour покраски/обоев без стоимости материалов).

Зоны объекта: [zones.md](./zones.md).

## 1. Зоны и замеры

В блоке **Зоны и замеры**:

- **Общие работы** — параметры замера стен раздела;
- **зоны** — площади стен зоны для сценариев «Применить к → зона».

| Поле (Общие работы) | Что указать |
|------|-------------|
| **Площадь стен, м²** | Общая площадь стен. Часто подставляется, если частное поле пустое. |
| **Демонтаж, м²** | Площадь покрытий, которые снимаем. |
| **Штукатурка / Шпаклёвка / Финиш, м²** | Площади под соответствующие работы. |
| **Откосы / Углы, м. пог.** | Погонные метры. |
| **Высота, м** | Для заметки; **в текущих сценариях объёмы от неё не считаются.** |
| **Комментарий замерщика** | Заметки по объекту. |

Заполнение полей **само** работы в итог не включает.

## 2. Быстрые действия

Кнопки подставляют объёмы в строки списка и **не включают** работы.
Откосы и углы в типовые сценарии **не входят** — при необходимости включите строки сами.

## 3. Сценарии стен

Select **«Применить к»**:

- **Общие работы** — canonical-строки, объёмы из замера раздела;
- **зона** — строки зоны, объёмы из полей зоны (стены / демонтаж / штукатурка / шпаклёвка / финиш / откосы / углы).

Повтор к той же зоне **обновляет** строки без дублей.

Два главных выбора сценария:

1. **Состояние стен** — с нуля, после демонтажа, предчистовая, только демонтаж, локально, только финиш.
2. **Целевой результат** — без финиша / под обои / под покраску.

**Финиш (обои или покраска)** добавляется только при цели «под обои» или «под покраску».
Для «только демонтаж» и «локальное выравнивание» финиш в сценарии не ставится.

---

### Стены с нуля под обои

Грунт, маяки, гипсовая штукатурка, базовая шпаклёвка, шлифовка, поклейка (тип обоев в сценарии).

**Проверить:** цементная штукатурка вместо гипса; тип обоев; откосы/углы вручную.

---

### Стены с нуля под покраску

То же основание + финишная шпаклёвка, стеклохолст, финишная шлифовка, покраска (слои в сценарии).

---

### После демонтажа под обои / под покраску

Как «с нуля» соответствующего финиша, плюс обеспыливание.

---

### Предчистовая под обои / под покраску

Без полного штукатурного пакета «с нуля». Под покраску — со стеклохолстом и финишной шпаклёвкой.

---

### Только демонтаж

Одна работа снятия покрытия (обои, краска, штукатурка, плитка, стеклохолст…). Финиш не добавляется.

---

### Локальное выравнивание

Точечное выравнивание без полного цикла. Финиш не добавляется.

---

### Только финиш: обои / покраска

Основание готово — только выбранный финиш. При «только покраска» стеклохолст/финишная шпаклёвка в этот режим не входят.

## 4. Строки сметы

- **Поиск** по названию, группе, зоне, комментарию (на расчёт не влияет).
- **Добавить работу из прайса** — в общие работы или зону (по клику).
- **Ручная строка** — своя позиция; можно удалить.
- Строки зон можно удалить; базовые строки прайса — выключить.

## Что сценарии стен не покрывают автоматически

- **Материалы**
- Перегородки ГКЛ, кладку, звукоизоляцию, чистовую плитку
- Откосы и углы (добавляйте вручную)
- Цементную штукатурку вместо гипсовой «с нуля» — при необходимости вручную
