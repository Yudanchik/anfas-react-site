# Раздел «Потолки»

Краткая инструкция для сметчика. Сценарий — быстрый черновик: после применения строки можно править вручную.
**Материалы не считаются** — только работы (в т.ч. labour покраски без стоимости краски, холста, шпаклёвки как материала).

Зоны объекта: [zones.md](./zones.md).

## 1. Зоны и замеры

В блоке **Зоны и замеры**:

- **Общие работы** — параметры замера потолков раздела;
- **зоны** — площади потолка зоны для сценариев «Применить к → зона».

| Поле | Что указать |
|------|-------------|
| **Площадь потолка, м²** | Общая площадь. Часто подставляется, если частное поле пустое. |
| **Демонтаж, м²** | Площадь покрытий, которые снимаем с потолка. |
| **Штукатурка / Шпаклёвка / Финиш, м²** | Площади под соответствующие работы. |
| **Комментарий замерщика** | Заметки по объекту. |

Заполнение полей **само** работы в итог не включает.

## 2. Быстрые действия

Кнопки подставляют объёмы в строки списка и **не включают** работы.

## 3. Сценарии потолков

Select **«Применить к»**:

- **Общие работы** — canonical-строки, объёмы из замера раздела;
- **зона** — строки зоны, объёмы из полей зоны (потолок / демонтаж / штукатурка / шпаклёвка / финиш).

Повтор к той же зоне **обновляет** строки без дублей.

Два главных выбора:

1. **Состояние потолка** — с нуля, после демонтажа, предчистовая, только демонтаж, локально, только финиш.
2. **Целевой результат** — без финиша / под покраску.

**Покраска** добавляется только при цели «под покраску».
Для «только демонтаж» и «локальное выравнивание» финиш в сценарии не ставится.

---

### Потолок с нуля под покраску

Грунт глубокого проникновения, маяки, штукатурка потолка, снятие маяков, шпаклёвка 2 слоя, шлифовка; при цели «под покраску» — финишная шпаклёвка, стеклохолст, финишная шлифовка, покраска (слои в сценарии).

**Проверить:** нужна ли штукатурка вообще; слои краски; стеклохолст.

---

### Потолок с нуля без финиша

Та же подготовка и шпаклёвка **без** покраски и стеклохолста.

---

### После демонтажа под покраску

Выбранный демонтаж покрытия + обеспыливание + цепочка «с нуля» под покраску.

---

### Предчистовой потолок под покраску

Без полного штукатурного пакета: обеспыливание, грунт в 1 слой, шпаклёвка 2 слоя, шлифовка; под покраску — финишная шпаклёвка, стеклохолст, финишная шлифовка, покраска.

---

### Только демонтаж

Одна работа снятия покрытия (краска, штукатурка, шпаклёвка, обои, ГКЛ с каркасом, Армстронг/Грильято, натяжной, панели…). Финиш не добавляется.

---

### Локальное выравнивание

Локальная шпаклёвка до 3 мм + шлифовка потолка. Без полной штукатурки и покраски.

---

### Только финиш / покраска

Только выбранные слои покраски потолка — без цепочки подготовки.

---

## 4. Что не входит в раздел и сценарии

- Монтаж ГКЛ-потолков и коробов
- Потолочные карнизы / плинтусы
- Монтаж Armstrong / Грильято / реечных (есть только **демонтаж**)
- Монтаж натяжного потолка (в прайсе нет; есть только демонтаж)
- Кабель / электрика на потолке
- Звукоизоляция потолка
- Материалы (краска, холст, смеси)
- Вывоз мусора (смотрите раздел **Полы** или ручную строку)

Нужное из этого — ручная строка или другой раздел позже.

## 5. Строки, поиск, итог

В **Строках сметы**: поиск, «Добавить работу из прайса», «Добавить ручную строку», правка объёмов/цен/коэффициентов.

**Итоговая смета** внизу страницы показывает дерево: **Полы / Стены / Потолки / Плитка** → общие работы или зона → строки.
