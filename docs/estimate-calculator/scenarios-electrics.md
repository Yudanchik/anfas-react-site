# Раздел «Электрика»

Краткая инструкция для сметчика. Сценарий — быстрый черновик: после применения строки можно править вручную.
**Материалы не считаются** — только работы (кабель, автоматы, щит, розетки, светильники, гофра как изделия — вне сметы).

**Источник цен:** PDF-прайс `anfas-price-list.pdf`. Публичный preview на сайте — только сверка.

Зоны объекта: [zones.md](./zones.md).

Полный рабочий процесс и выдача PDF: [customer-workflow.md](./customer-workflow.md).

## 1. Зоны и замеры

В блоке **Зоны и замеры** заполняют **счётчики**, а не только м²:

- **Общие работы** — параметры раздела;
- **зоны** — счётчики зоны для сценариев «Применить к → зона».

Поля сгруппированы компактно:

| Группа | Поля | Единицы |
|--------|------|---------|
| **Точки** | Розетки, выключатели, световые точки, слаботочка, подрозетники, распаечные коробки | шт. / точка |
| **Трассы** | Штробы, кабель | м. пог. |
| **Щит** | Модули щита | шт. |
| **Тёплый пол / техника** | Эл. тёплый пол, подключения техники | м² / шт. |

Комментарий — заметки по объекту (общие) или по зоне.

Заполнение полей **само** работы в итог не включает.

## 2. Быстрые действия

Кнопки подставляют количества в строки списка и **не включают** работы: розетки, выключатели, свет, штробы, кабель, тёплый пол.

## 3. Сценарии электрики

Select **«Применить к»**:

- **Общие работы** — canonical-строки, объёмы из счётчиков раздела;
- **зона** — в списке только **имя** зоны; строки зоны, объёмы из полей зоны.

Если у зоны задан **тип**, в select сценариев показываются **только подходящие**:

- кухня → сценарий «Электрика кухни» + универсальные;
- санузел → «Электрика санузла» + универсальные;
- комната / коридор → «Перекоммутация комнаты» + универсальные;
- общие работы и тип «Другое» → все сценарии.

Неподходящие нельзя выбрать и применить. Тип зоны правится в карточке зоны.

Повтор к той же зоне **обновляет** строки без дублей.

**Важно:** сценарии включают только **типовой** набор. Редкие labour-работы (лотки, тяжёлая люстра, магнитный шинопровод и т.п.) — через **«Добавить работу из прайса»**.

Включаются только строки с рассчитанным положительным объёмом. При пустых нужных счётчиках применение недоступно; сообщения считают фактически выбранные строки. Работы с ручным количеством (например, отдельная проверка) добавляйте из прайса. Нулевой новый замер не удаляет ранее выбранную работу: её нужно отключить явно.

---

### Электрика квартиры с нуля

Разметка, штробы, кабель, отверстия/подрозетники, коммутация, корпус и сборка щита на 12/18/24 модуля по счётчику, розетки/выключатели, точечный свет. Отдельные автоматы/УЗО не добавляются поверх пакетной сборки автоматически.

**Не включает:** материалы, редкие лотки/шинопроводы, выезд электрика.

---

### Перекоммутация комнаты

Разметка точек, штроба в кирпиче, кабель, отверстия, подрозетники, розетки/выключатели, точечный свет.

---

### Электрика кухни

Штробы/кабель, подрозетники, розетки и общая строка подключения техники. Один счётчик техники не размножается на варочную, духовку и вытяжку одновременно. Специальные подключения и отдельные трассы добавляйте из прайса с собственным количеством.

---

### Электрика санузла

Штробы/кабель, подрозетники, влагозащищённая розетка, точечный свет, заземление ванны, подключение полотенцесушителя к готовой линии.

---

### Только освещение

Монтаж точечных светильников по количеству световых точек. Подвесные, люстры и другие типы выбирайте отдельно из прайса; один светильник не учитывается одновременно двумя типами монтажа.

---

### Розетки и выключатели

Монтаж и подключение розеток/выключателей в готовые подрозетники.

---

### Слаботочные сети

Прокладка UTP, монтаж RJ45, тестирование интернет-линий.

---

### Только электрощит

Корпус и сборка одного щита до 12/18/24 модулей по счётчику. При 0 модулях сценарий недоступен; более крупный или нестандартный щит собирайте из прайса. Не добавляйте отдельный монтаж модулей поверх пакетной сборки без проверки состава работ.

---

### Только демонтаж электрики

Демонтаж розеток/выключателей и старого кабеля по счётчикам. Комплекс «старая электрика» доступен из прайса, но не добавляется вместе с поштучным демонтажом автоматически.

---

## 4. Редкие работы из прайса

В **Строки сметы** → «Добавить работу из прайса» доступен широкий whitelist labour-позиций PDF (штробление, гофра/лоток как **работа**, щит, свет, слаботочка, проверки…).

**Не входят в mapping:** кабель/автоматы/щит/светильники как товары; TV с кронштейном; Wi‑Fi/домофон при смешении с оборудованием; водяной тёплый пол; заделка штроб (общестрой); выезд 15k.

## 5. Единицы

Допустимы: **точка**, **шт.**, **м. пог.**, **м²**, **комплекс**, **выход**.  
Формула: `количество × цена × коэффициент`.

## 6. Пересечения с другими разделами

| Тема | Где считать |
|------|-------------|
| Заделка штроб | Общестрой / стены — не в электрике |
| Водяной тёплый пол | **Сантехника** (не электрика) |
| Гидроизоляция санузла | Полы |
| Светильники Armstrong / Грильято | Отдельные позиции потолков / прайса — не дублировать без нужды |

## 7. Итог

Раздел **Электрика** появляется в **Итоговой смете**, когда есть включённые строки. Удаление зоны убирает и электрические строки этой зоны.
