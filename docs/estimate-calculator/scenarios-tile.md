# Раздел «Плитка»

Краткая инструкция для сметчика. Сценарий — быстрый черновик: после применения строки можно править вручную.
**Материалы не считаются** — только работы (плитка, клей, затирка как материал, СВП, профили как комплектующие — вне сметы).

**Источник цен:** PDF-прайс `anfas-price-list.pdf`. Публичный preview на сайте — только сверка.

Зоны объекта: [zones.md](./zones.md).

## 1. Зоны и замеры

В блоке **Зоны и замеры**:

- **Общие работы** — параметры замера плитки раздела;
- **зоны** — площади плитки зоны для сценариев «Применить к → зона».

| Поле | Что указать |
|------|-------------|
| **Плитка пола, м²** | Площадь облицовки пола / демонтажа плитки пола. |
| **Плитка стен, м²** | Площадь облицовки стен / демонтажа плитки стен. |
| **Фартук, м²** | Площадь кухонного фартука (не «комплекс» из прайса). |
| **Подрезка / кромка, м. пог.** | Длина реза, ступеней, бортов и т.п. |
| **Углы / примыкания, м. пог.** | Углы, герметизация, плинтус. |
| **Отверстия, шт.** | Выпилы / отверстия в плитке. |
| **Замена плиток, шт.** | Локальная замена одной плитки. |
| **Комментарий** | Заметки по объекту. |

Заполнение полей **само** работы в итог не включает.

## 2. Быстрые действия

Кнопки подставляют объёмы в строки списка и **не включают** работы.

## 3. Сценарии плитки

Select **«Применить к»**:

- **Общие работы** — canonical-строки, объёмы из замера раздела;
- **зона** — в списке только **имя** зоны (без типа рядом); строки зоны, объёмы из плиточных полей зоны.

Если у зоны задан **тип**, в select сценариев показываются **только подходящие** (санузел — санузлные + универсальные; кухня — фартук + универсальные; комната/коридор — универсальные). Для общих работ и типа «Другое» видны все сценарии. Неподходящие нельзя выбрать и применить (apply-guard). Тип зоны правится в карточке зоны.

Повтор к той же зоне **обновляет** строки без дублей.

Дополнительные выборы (когда нужны):

1. **Формат плитки** — 301–1300 / 1301–1700 / крупный формат / мозаика / мелкоштучка.
2. **Затирка** — цементная / эпоксидная / без затирки (для ремонта).
3. **Поверхности демонтажа** — пол / стены / оба (для сценариев с демонтажем).

**Гидроизоляция в сценарии плитки не добавляется.**  
Если для санузла нужна гидроизоляция — добавьте её во вкладке **Полы** (мокрые зоны).

---

### Санузел с нуля

Обеспыливание, грунтование, раскладка; облицовка выбранным форматом (пол + стены); затирка и очистка (если выбрана).

**Не включает:** демонтаж, гидроизоляцию, материалы.

**Проверить:** формат; нужна ли гидро через **Полы**; углы / отверстия вручную.

---

### Замена плитки в санузле (демонтаж плитки)

**Явно включает демонтаж плитки пола и/или стен** (по выбору поверхностей) + подготовку + облицовку + затирку.

**Не включает:** гидроизоляцию.

**Проверить:** площади демонтажа и облицовки; не дублировать демонтаж ещё и во вкладках Полы/Стены.

---

### Плитка на пол

Облицовка выбранным форматом по площади пола + затирка (если выбрана).

---

### Плитка на стены

Облицовка выбранным форматом по площади стен + затирка (если выбрана).

---

### Кухонный фартук

Раскладка + облицовка по площади **фартука** (м²), не комплексная позиция «35000».

---

### Крупный формат

Крупноформатная облицовка (по умолчанию 1701–3600 или выбранный формат) + раскладка + подготовка кромки + отверстие (пакет черновика).

---

### Только демонтаж плитки

Демонтаж плитки пола и/или стен — без облицовки и затирки. В названии сценария явно указан демонтаж.

---

### Только затирка / ремонт

Цементная или эпоксидная затирка с очисткой; если затирка «нет» — локальная замена одной плитки.

---

## 4. Что не входит в раздел и сценарии

- **Гидроизоляция** — канон во вкладке **Полы** / мокрые зоны
- Плитка, клей, затирка **как материал**
- СВП (система выравнивания) как материал/комплект
- Металлические профили / уголки как материал
- Мембраны
- Люки и экраны ванной, если позиция смешивает работу и комплектующие
- Комплексный фартук «35000» и строительный комплекс душевого поддона
- Вывоз мусора (смотрите **Полы** или ручную строку)

Нужное из этого — ручная строка или другой раздел.

## 5. Пересечения с Полами и Стенами (не задублировать)

| Работа | Где ещё есть | Как не дублировать |
|--------|--------------|--------------------|
| Демонтаж плитки пола | Полы | Если уже включили в **Плитке**, не включайте тот же объём в **Полах** |
| Демонтаж плитки стен | Стены | Аналогично — один раздел на один объём |
| Укладка плитки пола (finish) | Полы | Для санузла/стен/фартука канон — вкладка **Плитка**; в Полах позиция оставлена для совместимости |
| Гидроизоляция | Полы | Только через **Полы**; сценарии Плитки её не добавляют |

У каждой вкладки **свои** ключи прайса (даже при одинаковом названии и цене). Итог суммирует разделы отдельно — двойное включение даст двойную сумму.

## 6. Строки, поиск, итог

В **Строках сметы**: поиск, «Добавить работу из прайса», «Добавить ручную строку», правка объёмов/цен/коэффициентов.

**Итоговая смета** внизу страницы показывает дерево: **Полы / Стены / Потолки / Плитка** → общие работы или зона → строки.
