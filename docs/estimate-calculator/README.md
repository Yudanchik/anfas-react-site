# Внутренний калькулятор сметы

Это внутренний инструмент для черновой сметы **работ** по ремонту.
Страница: `/internal/estimate` (не для публичного сайта).

**Материалы пока не считаются** — в итоге только стоимость работ.
Черновик сметы **сохраняется локально** в браузере (на этом компьютере).

## Что уже есть

| Возможность | Кратко |
|-------------|--------|
| Разделы **Полы** и **Стены** | Отдельные вкладки с своими сценариями и строками |
| **Зоны объекта** | Кухня, санузел и т.п. — общий список на объект |
| **Общие работы** | Замер и сценарии без привязки к зоне |
| **Сценарии по зонам** | Типовой набор работ на «Общие работы» или на выбранную зону |
| **Добавить работу из прайса** | Одна позиция из прайса в общие работы или в зону |
| **Ручные строки** | Своя работа не из прайса; можно удалить |
| **Поиск по строкам** | Быстро найти работу в длинном списке (на расчёт не влияет) |
| **Итоговая смета** | Дерево: раздел → общие работы / зона → строки |

## Как пользоваться

1. Вверху смотрите краткий обзор по разделам (сколько позиций и сумма).
2. Выберите вкладку **Полы** или **Стены**.
3. В **Зоны и замеры** заполните **Общие работы** и/или площади зон.
4. В сценариях выберите **Применить к** → общие работы или зона → **Применить**.
5. При необходимости точечно: «Добавить работу из прайса» / «Добавить ручную строку» в блоке **Строки сметы**.
6. В таблице правьте объёмы, цены, коэффициенты; лишние clone/ручные строки можно удалить.
7. Внизу раскройте **Итоговую смету** — дерево по разделам и зонам.

Сценарий — быстрый черновик, не финальный ответ. После применения всегда проверяйте состав и объёмы.
