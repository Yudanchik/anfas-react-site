# Внутренний калькулятор сметы

Это внутренний инструмент для черновой сметы **работ** по ремонту.
Страница: `/internal/estimate` (не для публичного сайта).

Сейчас в калькуляторе два раздела:

- **Полы** — [инструкция](./scenarios-floors.md)
- **Стены** — [инструкция](./scenarios-walls.md)

## Как пользоваться в общих чертах

1. Сметчик заполняет **параметры замера** (площади и комментарий).
2. Выбирает **сценарий** (типовой набор работ) и нажимает «Применить».
3. Сценарий добавляет в смету готовые строки с объёмами — это **черновик**, а не финальный ответ.
4. Дальше всё можно поправить вручную: включить или выключить работу, изменить объём, цену, коэффициент, комментарий.
5. При необходимости добавить **ручную строку**, которой нет в списке.
6. Внизу страницы **итоговая смета** собирает выбранные позиции по разделам (Полы и Стены вместе).

**Материалы пока не считаются** — только работы.

Сценарий не заменяет проверку сметчиком: после применения всегда смотрите состав и объёмы.
