# Раздел «Сантехника»

Краткая инструкция для сметчика. Сценарий — быстрый черновик: после применения строки можно править вручную.
**Материалы не считаются** — только работы (трубы, фитинги, приборы, коллектор, фильтр, счётчик как изделия — вне сметы).

**Источник цен:** PDF-прайс. Публичный preview на сайте — только сверка.

Зоны объекта: [zones.md](./zones.md).

Полный рабочий процесс и выдача PDF: [customer-workflow.md](./customer-workflow.md).

## 1. Зоны и замеры

В блоке **Зоны и замеры** заполняют **счётчики и длины**, а не только м²:

- **Общие работы** — параметры раздела;
- **зоны** — счётчики зоны для сценариев «Применить к → зона».

Поля сгруппированы компактно:

| Группа | Поля | Единицы |
|--------|------|---------|
| **Точки** | Водорозетки, выводы канализации | шт. |
| **Трассы** | Водопровод, канализация | м. пог. |
| **Коллектор / учёт** | Коллекторные узлы / шкафы | шт. |
| **Приборы** | Унитазы, раковины/мойки, ванны, души, смесители, инсталляции, трапы, стиралка, ПММ, водонагреватели, водяные полотенцесушители | шт. |
| **Водяной ТП** | Площадь водяного тёплого пола | м² |

Комментарий — заметки по объекту (общие) или по зоне.

Заполнение полей **само** работы в итог не включает.

## 2. Быстрые действия

Кнопки подставляют количества в строки списка и **не включают** работы: трубы воды, канализация, водорозетки, выводы канализации, водяной тёплый пол.

## 3. Сценарии сантехники

Select **«Применить к»**:

- **Общие работы** — canonical-строки, объёмы из счётчиков раздела;
- **зона** — в списке только **имя** зоны; строки зоны, объёмы из полей зоны.

Если у зоны задан **тип**, в select сценариев показываются **только подходящие**:

- санузел → «Сантехника санузла с нуля», «Замена сантехники», «Ванная», «Туалет» + универсальные;
- кухня → «Кухня» + универсальные;
- общие работы и тип «Другое» → все сценарии.

Неподходящие нельзя выбрать и применить. Тип зоны правится в карточке зоны.

Повтор к той же зоне **обновляет** строки без дублей.

**Важно:** сценарии включают только **типовой** набор. Редкие labour-работы (стояки, редкие диаметры, стекло-кабины, встроенные корпуса и т.п.) — через **«Добавить работу из прайса»**.

Сценарий включает только строки с положительным рассчитанным количеством. Пустые счётчики не создают ложный успешный результат. Работы с ручным количеством, включая часть проверок, добавляйте из прайса. Нулевой новый замер не удаляет уже выбранную работу автоматически.

Одна длина канализации не подставляется одновременно в d32–50 и d110. В общем сценарии используется d32–50, в сценарии туалета d110; другие участки задайте отдельными строками. Один счётчик смесителей также не размножается на несколько типов: общий сценарий использует смеситель раковины, сценарий ванной — смеситель ванны. Для смешанного набора уточните строки из прайса.

---

### Сантехника санузла с нуля

Разводка канализации и воды, водорозетки, инсталляция с подключениями, унитаз на инсталляцию, раковина, акриловая ванна и один выбранный тип смесителя по заполненным счётчикам. Опрессовку и пуск с ручным количеством уточните из прайса.

**Не включает:** материалы/приборы как товар, отопление, штробы дм³, выезд 15k, редкие стояки.

---

### Замена сантехники в санузле

Демонтаж унитаза / раковины / ванны / смесителей + финишный монтаж к готовым выводам + проверка финишной сантехники.

---

### Кухня

Канализация и вода к мойке, кухонная мойка и смеситель, посудомоечная машина, опрессовка водоснабжения.

---

### Ванная

Акриловая ванна (или готовый поддон) + смесители / сифон — без полной черновой разводки всего санузла.

---

### Туалет

Инсталляция с подключениями, унитаз на инсталляцию, короткие трассы воды/канализации и водорозетка.

---

### Коллекторный узел

Шкаф, балка, подключение магистрали, фильтр / редуктор / счётчик (как **монтаж**), опрессовка.

---

### Канализация

Разметка, трубы d32–50, фиксация вывода и уклон по заполненным счётчикам. d110 и пробная проливка с ручным количеством добавляются отдельно.

---

### Водоснабжение

Разметка, труба d16–20, водорозетка и фиксация, опрессовка водоснабжения.

---

### Подключение приборов

Финишный монтаж унитаза / раковины / смесителя / стиралки / ПММ без черновой разводки + проверка финиша.

---

### Только демонтаж

Демонтаж унитаза, раковины, ванны, смесителей.

---

## 4. Редкие работы из прайса

В **Строки сметы** → «Добавить работу из прайса» доступен широкий whitelist labour-позиций PDF (канализация/вода, соединения, водяной ТП, коллектор, инсталляция/трапы, встроенные смесители, финиш, проверки…).

**Не входят в mapping:** трубы/фитинги/приборы как товары; отопление (радиаторы, котлы, конвекторы); электрический полотенцесушитель и электрический ТП; штробы дм³; заделка штроб; выезд 15k.

## 5. Единицы

Допустимы: **точка**, **шт.**, **м. пог.**, **м²**, **компл. / комплекс**.  
Формула: `количество × цена × коэффициент`.

## 6. Пересечения с другими разделами

| Тема | Где считать |
|------|-------------|
| **Водяной** тёплый пол | **Сантехника** |
| **Электрический** тёплый пол / эл. полотенцесушитель | Электрика |
| Отопление (радиаторы, котлы…) | Out MVP — follow-up |
| Штробы инженерии дм³ / заделка штроб | Out / общестрой |
| Гидроизоляция / опалубка поддона | Полы |
| Облицовка поддона / борт | Плитка |
| Эл. водонагреватель (если в прайсе электрики) | Электрика |

Порядок в санузле: сначала трубы / инсталляция / трап (сантехника), затем плитка.

## 7. Итог

Раздел **Сантехника** появляется в **Итоговой смете**, когда есть включённые строки. Удаление зоны убирает и сантехнические строки этой зоны.
