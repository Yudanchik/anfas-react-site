# Полы: дерево вопросов и работ для согласования

Актуальный сводный документ: [деревья и вопросы по всем разделам](scenarios-and-client-questions.md).

Калькулятор считает **работы**, не материалы. Один мастер из трёх шагов применяется отдельно к помещению; площади демонтажа, выравнивания и гидроизоляции могут отличаться. Вопросы слева, список и объёмы справа. Отдельные старые кнопки сценариев убраны, дополнительные работы добавляются из прайса в блоке строк.

## Что сейчас собирает основной маршрут

| Вопрос                   | Ответ                                                       | Работы, попадающие в черновик                                         | Количество                                    |
| ------------------------ | ----------------------------------------------------------- | --------------------------------------------------------------------- | --------------------------------------------- |
| Снимаем старое покрытие? | Нет / уже снято                                             | Нет повторного демонтажа                                              | —                                             |
|                          | Ламинат, линолеум, плитка, паркетная доска, стяжка до 70 мм | Одна соответствующая позиция демонтажа                                | Площадь демонтажа помещения                   |
| Как выравниваем?         | Не требуется                                                | Выравнивание не добавляется                                           | —                                             |
|                          | Ровнитель                                                   | Обеспыливание → грунтование → наливной пол                            | Уточнённая площадь стяжки, иначе площадь пола |
| Нужно шлифовать бетон?   | Не осмотрено / нет / да / другое или непрочное основание    | При «да» перед обеспыливанием добавляется шлифование. Без осмотра или при неподходящем основании маршрут не применяется | Площадь ровнителя |
|                          | Полусухая до/свыше 80 мм                                    | Подготовка → обеспыливание → грунтование → выбранная полусухая стяжка | Та же площадь                                 |
|                          | Мокрая до 50 / 50–80 / свыше 80 мм                          | Подготовка → обеспыливание → грунтование → выбранная мокрая стяжка    | Та же площадь                                 |
| Конструкция стяжки?      | Контактная / на полиэтиленовой плёнке / плавающая / неизвестно | Контактная оставляет грунт; на плёнке заменяет его укладкой плёнки. Плавающая и неизвестная требуют уточнения | Площадь стяжки |
| Нужна гидроизоляция?     | Нет / акриловая 1 или 2 слоя                                | Нет / одна соответствующая позиция                                    | Отдельная площадь мокрой зоны                 |
| Какое финишное покрытие? | Ламинат, замковый/клеевой кварцвинил, инженерная/паркетная доска на клей, ковровое покрытие на клей | Соответствующая работа монтажа; для ламината и замкового кварцвинила также подложка | Площадь пола |
| Какой плинтус? | Нет / пластик / МДФ / дюрополимер / скрытый | Соответствующая работа монтажа | Периметр минус ширина дверных проёмов |

Если выбранной работе не хватает замера, применение блокируется с конкретной причиной. Повторное применение маршрута в том же помещении заменяет его автоматические позиции, но не удаляет ручные строки. Плиточная облицовка учитывается в разделе «Плитка». Монтажа линолеума в предоставленном прайсе нет, поэтому цена для него не выдумана: добавьте ручную строку после согласования. Вывоз мусора остаётся отдельной работой.

## Вопросы заказчику

1. Какие типы существующего покрытия и основания встречаются чаще всего? Нужны ли отдельные варианты для деревянного пола, нескольких слоёв покрытия и демонтажа стяжки **свыше 70 мм**? Как измерять каждую работу?
2. По каким измерениям и допускам выбирать «ничего», ровнитель, мокрую или полусухую стяжку? Какие фактические диапазоны толщины поддерживаются **применяемыми материалами**, а когда нужен проектный расчёт и отдельная цена?
3. Для контактной и стяжки на полиэтиленовой плёнке мастер теперь разделяет грунт и плёнку. Подтвердите допустимые толщины и обязательные операции: демпферная лента, маяки, сетка, шумоизоляция, керамзит, уход и швы. Плавающую стяжку пока не выдаём за готовый маршрут. Какие операции уже включены в цену устройства стяжки, чтобы не считать дважды?
4. Ответ о шлифовании бетона перед наливным полом теперь есть в мастере; подтвердите, когда оно нужно и достаточно ли его для подготовки. Когда требуется ремонт или замена слабого основания, а когда сначала нужна стяжка? Как учитывать 2–3 прохода грунта на впитывающем основании: оплачиваются ли они по отдельности и какой тариф применить?
5. Где именно нужна гидроизоляция: вся площадь санузла, только зона душа или иные участки? Считать ли стены, примыкания, углы и проходки труб отдельно? Сколько слоёв и какой тип системы используется? Может ли гидроизоляция идти **после** выбранного выравнивания?
6. Какие финишные покрытия входят в типовые сметы? Нужно ли включить в этот мастер подложку, укладку, подрезку, клей, прикатку, плинтус? Для плитки определить границу с разделом «Плитка».
7. Как считать вынос/вывоз мусора: по объёму, рейсу, этажу и наличию лифта? Нельзя достоверно вывести рейсы из площади демонтажа без замера объёма.
8. Дайте 2–3 обезличенных готовых смет с замерами, толщинами и выбранной системой пола: локальный ремонт, мокрая/полусухая стяжка, ровнитель, мокрая зона, разные покрытия. Сверим позиции и объёмы построчно и зафиксируем допустимое расхождение.

Технические ориентиры относятся к **конкретной системе**, а не ко всякой стяжке: [КНАУФ F231](https://www.knauf.ru/systems/poly/f-231/), [КНАУФ ОП 131](https://www.knauf.ru/systems/poly/op-131/). До ответов и сверки с реальными объектами маршрут остаётся проверяемым черновиком.

Правила маршрута: `src/entities/estimate/model/floors/apply-floor-preset.ts`; вопросы и предпросмотр: `src/features/floor-estimate/ui/FloorEstimatePresets.tsx`.
