5. ИНФОРМАЦИОННЫЙ БАННЕР
==================================================

Добавь глобальный информационный баннер в стилях проекта «Анфас».

Баннер сообщает об использовании localStorage. Это не система управления согласием на аналитику.

Текст:

`Сайт использует локальное хранилище браузера для корректной работы интерфейса.`

Ссылка:

`Подробнее`

Маршрут ссылки:

`/cookies`

Кнопка:

`Понятно`

Не добавляй:

- «Принять все»;
- «Отклонить»;
- «Только необходимые»;
- «Настроить».

ЛОГИКА

Используй ключ:

```ts
const STORAGE_KEY = 'anfas-cookie-notice-v1'
```

Баннер должен:

- показываться при первом посещении;
- скрываться после нажатия «Понятно»;
- записывать `anfas-cookie-notice-v1 = true` в localStorage;
- не показываться после перезагрузки;
- снова появляться после удаления ключа;
- скрываться в текущем состоянии интерфейса, даже если запись в localStorage невозможна.

Не используй document.cookie.

Сначала проверь, есть ли в проекте безопасный storage hook. Если есть подходящий — используй его. Если нет, достаточно минимальной локальной реализации:

```tsx
const STORAGE_KEY = 'anfas-cookie-notice-v1'

const [isReady, setIsReady] = useState(false)
const [isClosed, setIsClosed] = useState(false)

useEffect(() => {
  try {
    setIsClosed(window.localStorage.getItem(STORAGE_KEY) === 'true')
  } catch {
    setIsClosed(false)
  } finally {
    setIsReady(true)
  }
}, [])

const handleClose = () => {
  try {
    window.localStorage.setItem(STORAGE_KEY, 'true')
  } catch {
    // Баннер всё равно скрывается в текущем состоянии интерфейса.
  }

  setIsClosed(true)
}

if (!isReady || isClosed) {
  return null
}
```

Не обращайся к window при вычислении начального состояния.

Не добавляй сложный универсальный hook с throttling и таймерами только ради одного значения.
